# 首次使用说明（中控啵比直播助手 v1.6.5）

## 这是什么

直播中控助手：帮你在直播时自动弹窗商品、自动发言、自动回复评论、一键发红包、批量发弹幕。
先免费试用 72 小时，觉得好用再买卡密。

## 安装前准备

- Windows 10 / 11，64 位。
- **电脑上要装有 Chrome 或 Edge 浏览器**（任意一个就行，软件用它打开直播间）。
  没装的话先装一个，不然软件连不上直播间。
- 安装过程需要联网。

## 安装

1. 下载安装包 `中控啵比直播助手_1.6.5_windows_x64.exe`，双击打开。
2. 按向导点下一步装完，桌面会出现图标。
3. 双击图标启动。

## 第一次打开：自动试用 72 小时

- 第一次打开就自动开始 72 小时免费试用，不用注册、不用输卡密。
- 试用从第一次打开那一刻开始算（72 个小时的墙钟时间，不是累计使用时长）。
- 剩余时间在两处能看到：直播控制台页面顶上的横幅、设置页最上面的「卡密授权」。
- 试用期内自动弹窗、自动发言、自动回复、发红包、批量弹幕五个功能都能用。
- 重启软件不会刷新试用；卸载重装也不会（只要没手动删应用数据）。

## 连接直播间开始用

打开软件后按首页的「三步上手」走：连接直播控制台 → 配好要用的功能 → 开始。
连不上时先看两点：Chrome / Edge 装了没有、直播间链接对不对。

## 批量弹幕（小号轮番发文案）

左侧点「批量弹幕」，三步走：

1. **登录小号**：5 个槽位（shuijun1~5），每个点「扫码登录」，二维码直接在应用里显示，用对应的抖音小号 App 扫。**只用小号，绝不用主力号 / 工作号。**
2. **写文案**：文案库里一行一条，空行分组——一组由同一个号发完。组内间隔固定（第 1→2 句 50–70 秒，之后 105–135 秒），组间间隔在页面上改（默认 60–120 秒，下限至少 5 秒）。
3. **开始**：填好直播间号，点「开始任务」后会先弹确认框，完整展示本次要发的分组（组数、总条数、前几条预览），必须点「文案我看过了，确认开始」才会真正启动；不确认不启动。

注意：

- 票据约 1 小时过期，过期后对应卡片会提示，重新扫码就行；某个号触发风控会被自动停用，其余号继续发。
- 如果跳出短信验证，把手机收到的 6 位验证码输进页面点提交。
- 封号风险自担，工具不保证送达；文案由你自己确认。

## 试用结束后：输卡密继续用

1. 找客服买卡密（第一版人工收款、人工发卡）。
2. 打开软件 → 左侧「应用设置」→ 最上面「卡密授权」→ 粘贴卡密 → 点「激活」。
3. 激活成功会显示有效期至哪天、还剩多少天；剩 7 天内会提醒续费。
4. 试用期内也可以提前输卡密激活，卡密优先于试用。
5. 卡密到期后要续费：找客服买新卡，重新输入即可。**卡密到期后不会重新获得 72 小时试用。**

## 常见问题

- **卡密不对**：检查是不是多复制了空格、是不是输错了字符。输错不会影响已经激活的有效卡密。
- **校验服务暂时不可用**：稍后再试一次，已激活的卡密不受影响。
- **软件升级后授权还在吗**：在。升级不会清除已激活的卡密，也不会重置试用。
- **换电脑了怎么办**：卡密不绑定电脑，在新电脑上重新输入同一张卡密就行；试用是按每台电脑第一次打开算的。
