# 卡密授权说明（离线版 v1）

买家输入卡密才能用自动弹窗、自动发言、自动回复、一键发红包这四项自动化功能。
连接中控台、AI 助手这些不拦。卡密校验全在本地完成，不用服务器。

## 卡密长什么样

`BOBI1.<payload>.<signature>`，一长串字符，复制粘贴用。

- payload 是 base64url 编码的 JSON：`{"v":1,"exp":过期时间的 unix 秒,"id":"随机编号"}`
- signature 是对 payload 部分的 Ed25519 签名

## 卖家怎么发卡

发卡脚本在 `scripts/gen-key.mjs`，私钥在 `scripts/license-private.key`（0600 权限，git 已忽略）。

```bash
# 第一次用：生成一对新密钥（已有私钥时会拒绝覆盖）
node scripts/gen-key.mjs --init

# 看公钥（第一次生成后，把打印出来的公钥贴到 electron/main/utils/license.ts 的 BOBI_LICENSE_PUBLIC_KEY 里）
node scripts/gen-key.mjs --pubkey

# 生成一张卡密，--days 是有效天数
node scripts/gen-key.mjs --days 365
node scripts/gen-key.mjs --days 30 --note 张三

# 校验一张卡密（发出去之前先验一下）
node scripts/gen-key.mjs --verify <卡密>
```

**私钥就是命。** 谁拿到 `scripts/license-private.key`，谁就能无限发卡。
不要发给任何人、不要提交到 git、不要放进网盘包、不要贴到群里。
丢了私钥只能换一对新的，换完之前发过的所有卡密全部失效。

## 买家怎么激活

打开软件 → 左侧「应用设置」→ 最上面「卡密授权」→ 粘贴卡密 → 点「激活」。
激活成功会显示有效期至哪天、还剩多少天；剩 7 天内会提醒续费。
卡密不对会明确提示「卡密不对」，过期了会提示「卡密已过期」。
卡密存在买家电脑本地，软件每次启动会重新校验一次。

## 免费试用 72 小时（v1.6.4 新增）

第一次打开软件，不用输卡密，自动获得 72 小时免费试用。试用从第一次打开那一刻开始算，
是墙钟 72 小时，不是累计用满 72 小时。试用期内自动弹窗、自动发言、自动回复、
一键发红包四个功能都能用。

- 试用期内也可以提前输卡密激活，卡密优先于试用。
- 一旦成功激活过卡密，试用即视为已消费：卡密到期后不会重新获得 72 小时试用。
- 输错卡密不会清除已经激活的有效卡密；校验服务暂时不可用时也会明确提示，不会把已激活的卡密判成无效。
- 试用开始时间只记第一次，重启软件、卸载重装（不删应用数据）都不会重置。
  手动删掉应用数据目录可以重置试用，这是纯本地方案接受的限制。
- 系统时间往回调延长不了试用：软件记着曾经见过的最大时间，回拨后按最大时间算。
  但一次回拨不会永久处罚用户，时间调回来后试用继续走。

## 为什么不用 HMAC

HMAC 是对称算法，校验方必须持有同一把密钥。密钥一旦放进应用代码，
任何人反编译都能拿它伪造卡密。所以这里用 Ed25519 非对称签名：
私钥只留在发卡脚本，应用里只放公钥。公钥只能验签、不能签发，
就算被人从应用里抠出来，也做不出新的卡密。

## 这个离线方案的实在限制

1. **已发出的卡密没法远程作废。** 只能等它自己过期。卖之前确认好天数；出问题只能换私钥（代价是所有已发卡密一起失效）。
2. **防的是随手分享，不是专业破解。** 校验在买家电脑本地跑，有心人改掉校验逻辑就能绕过。这是所有离线卡密方案的通病，不是一道完美的锁，是一道门槛。
3. **公钥和私钥是一对的。** 换私钥必须同步换 `electron/main/utils/license.ts` 里的公钥并重新打包发布，否则新卡密验不过、旧卡密也全失效。
4. **卡密不绑定电脑。** 一张卡密可以在多台电脑上用。想一机一码的话，要加机器码绑定，那是 v2 的事。
5. **系统时间。** 卡密校验看的是买家电脑的时间，买家把系统时间往回调能多蹭几天，
   调不回已过期的卡密。别指望它防时间作弊。
   72 小时试用另外记着曾经见过的最大时间，回拨时钟延长不了试用；
   长期回拨或删除应用数据仍可绕过，这是纯本地方案接受的 MVP 限制。
